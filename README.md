# AI Failure Reasoning Engine

## 1. Introduction
The AI Failure Reasoning Engine is a Python-based web application designed to analyze system failures and provide reasoning based on failure data.

It helps users understand failure patterns, analyze previous failures, and view analysis results through a web dashboard.

## 2. Objectives
- To identify system failure patterns.
- To analyze failure data.
- To provide reasoning for failures.
- To maintain failure history.
- To display analysis results through a dashboard.

## 3. Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON
- Visual Studio Code

## 4. Features
- Failure Analysis
- AI-Based Failure Reasoning
- Failure History Management
- Dashboard Visualization
- Confidence Analysis
- Clear History Option

## 6. Installation Steps

1. Clone the repository.

```bash
git clone https://github.com/pranjalkadam9696/AI-Failure-Reasoning-Engine.git
```

2. Open the project folder.

```bash
cd AI-Failure-Reasoning-Engine
```

3. Install required libraries.

```bash
pip install -r requirements.txt
```

4. Run the application.

```bash
python app.py
```

5. Open the application in your browser using the local URL displayed in the terminal.
